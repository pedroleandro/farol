# FAROL

Farol é um sistema web de gestão e acompanhamento de logística/fretes, desenvolvido para um cliente (não é um projeto pessoal seu). Ele nasceu a partir de uma planilha Excel que o cliente já usava para controlar pedidos, fretes e entregas — cheia de informações valiosas, mas difícil de visualizar e sujeita a erros manuais.
